# Third-party assets

## Tabler

`admin/assets/tabler/tabler.min.css` and `tabler.min.js` are the built Tabler
UI distribution, vendored so the admin panel works without a build step.

- Project: https://github.com/tabler/tabler
- License: MIT
- Copyright (c) Paweł Kuna

To upgrade, replace both files with the current release from the Tabler
distribution and keep this notice in place.
